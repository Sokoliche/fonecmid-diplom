# Инструкцию для специалистов заказчика по начальной настройке программы.

## Шаг № 1

### Пользователю "Администратор" необходимло заполнить константы:
  - "Токен управления Telegram - ботом" - заполняется токеном бота Telegram 
 Инструкция где найти (https://timeweb.com/ru/community/articles/token-bota-telegram-kak-sdelat-gde-vzyat-i-kuda-vstavlyat);
  - "Индикатор группы для оповещения" - заполняется идентификатором группы Telegram 
 Инструкция где найти (https://journal.sovcombank.ru/tehnologii/kak-uznat-id-telegram-podrobnaya-instruktsiya#h_8980432711743667285307);
  - "Номенклатура абонентская плата" - заполняется из справочника "Номенклатура", при необходимости создайте нужную номенклатуру ("Абонентская плата").
  - "Номенклатура работы специалиста" - заполняется из справочника "Номенклатура", при необходимости создайте нужную номенклатуру ("Работы специалиста").

------

## Шаг № 2

### Необходимо создать группу и бот в Telegram. 
Telegram нужен для отправки уведомлений о созданных документых "Обслуживание клиента" в котором указывается информация:
  - Номер и дата заявки;
  - Наименование клиента;
  - Имя специалиста которому адресована данная заявка;
  - дата и время проведения работ;
  - Описание проблемы (ошибки).
 Уведомления создаются при создании нового документа "Обслуживание клиента", а так же при изменении в документе "Даты" и "Специалиста".

------

## Шаг № 3

### Пользователю "Администратор" или "Кадровик-расчетчик": 
 - заполнить регистр сведений "Условия оплаты сотрудников" укажите процент от продаж у "Специалистов" и оклады у всех сотрудников
(ОКЛАД у сотрудников должен быть более 1).
 - заполнить справочник "Графики работ" видом работ, (например - пятидневка, шестидневка или два через два).
 - Открыть обработку "Заполнение графика работы" заполнить графы :
	"Выбор периода" выбрать за какой период заполнить график;
 	"Выходные дни" через запятую перечислеть порядковый номер выходного дня недели (пример 6,7 где 6 означает субботу, а 7 воскресенье);
	"График работы" выбрать график работы.
   Далее нажимаем кнопку "Заполнить", после проверяем корректную заполненость регистра сведений "График работы".
   Для расчетов в календарных дня необходимо отдельно создавать и заполнять график "График работы"

------

## Шаг № 4

### Пользователю "Администратор" в разделе: "Администрирование" - "Настройка пользователей и прав" - "Пользователи", создайте нужных пользователей.  
При создани пользователя на поле "Подразделение" для сотрудников - специалист написать "Специалисты", а для других сотрудников "Администрирование".
Во вкладе "Права доступа", назначить каждому пользователю соответствующий должности профиль группы должности. (например: Для менеджеров профиль груммы доступа - "Менеджер".
